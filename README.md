# Rafaq Messenger

A simple, beautiful group chat app inspired by Telegram, built with Kotlin and Jetpack Compose.

## Features
- One group chat only
- Modern chat UI
- Material 3 design
- Real-time messaging architecture ready for Firebase
- Local demo state for quick startup
- Clean MVVM structure

## Tech stack
- Kotlin
- Jetpack Compose
- Material 3
- ViewModel + StateFlow
- Firebase-ready architecture

## Run locally

1. Open in Android Studio
2. Let Gradle sync
3. Run the app on an emulator or device

## Notes
- Firebase configuration is intentionally left as a next step.
- This project is a clean app foundation and can be extended into a full production messaging app.
