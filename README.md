# Rafaq Messenger

This repository includes a simple modern web demo for a group chat app inspired by Telegram.

## Open the app

Open the file `index.html` in a browser to view the interface.

## Features
- Group chat layout
- Beautiful RTL design
- Responsive layout
- Send new message in real time
- Typing indicator simulation
